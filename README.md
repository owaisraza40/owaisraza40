## Selected projects

### ⚡ Flux — Windows download manager

An open-source desktop app built with **C#, .NET, and WPF**. Flux combines adaptive parallel downloads with persistent pause/resume, restart recovery, ordered queues, scheduling, and Chrome/Edge and Firefox integration.

<a href="https://github.com/owaisraza40/flux">
  <img src="https://raw.githubusercontent.com/owaisraza40/flux/main/docs/images/flux.png" alt="Flux Windows desktop interface showing its download management dashboard" width="100%" />
</a>

**Engineering focus:** segmented HTTP transfers, durable checkpoints, safe range handling, and browser-to-desktop communication.

`C#` `.NET` `WPF` `HTTP` `WebSockets` `JavaScript`

[**Explore the source →**](https://github.com/owaisraza40/flux) · [Download for Windows](https://github.com/owaisraza40/flux/releases) · [Architecture](https://github.com/owaisraza40/flux/blob/main/docs/ARCHITECTURE.md)

### ✈️ AeroNexus — Flight management system

A C++17 REST API paired with a React frontend for managing airlines, aircraft, flights, and operational records. Includes token-based authentication, role-based access, CSV persistence, and Docker configuration.

**Engineering focus:** API design, access control, and connecting a C++ backend to a web interface.

`C++17` `cpp-httplib` `React` `CSV` `Docker`

[**Explore the source →**](https://github.com/owaisraza40/AeroNexus-backend)

### 🧠 Sentiment Analysis — Text exploration notebook

A Python notebook exploring text cleaning, sentiment analysis, visualizations, and TF-IDF features. Documents the preprocessing steps and the reasoning behind transforming raw comments into numerical features.

**Data focus:** cleaning text, removing stopwords, exploring patterns, and understanding feature extraction.

`Python` `Pandas` `NLTK` `scikit-learn` `Matplotlib` `Jupyter`

[**Explore the notebook →**](https://github.com/owaisraza40/Review-Analysis-Sentiment-Analysis/blob/main/Sentiment%20Analysis.ipynb)
